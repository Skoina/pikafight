# 武俠皮遊：GitHub 網頁上傳版

這個資料夾就是網站根目錄。請把裡面的內容上傳，不要把「GitHub網頁上傳版」資料夾本身當成網站子資料夾。

1. 在 GitHub 建立公開 repository。
2. 在 repository 根目錄選 Add file → Upload files。第一次拖入本資料夾根目錄的全部檔案：index.html、全部 .js 與 README.md。按 Commit changes。
3. 再在 repository 根目錄選 Add file → Upload files。第二次只拖入整個 assets 資料夾。按 Commit changes。
4. 確認 repository 根目錄看得到 index.html、JavaScript 檔案和 assets 資料夾。
5. 到 Settings → Pages，Source 選 Deploy from a branch，Branch 選 main、/(root)，按 Save。等 Actions 部署成功後，從 Pages 頁面開啟網站。

GitHub 網頁每次最多上傳 100 個檔案；本包的 assets 共有 96 個檔案，因此分兩次上傳。
